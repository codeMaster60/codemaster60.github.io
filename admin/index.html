How do I get a token? (one time, 2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name it Portfolio admin, and set an expiry date.
  3. Repository access: Only select repositories → pick codemaster60.github.io.
  4. Permissions → Repository → Contents: Read and write.
  5. Generate, copy the token, and paste it above.

The token stays in this browser and is only ever sent to GitHub. Anyone else who opens this page can’t change anything without it.
